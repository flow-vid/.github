# Support

These repositories contain open-source media components and build recipes. They are not the FlowVid
application support tracker.

- Product help and feedback: <https://flow-vid.com/support>
- Downloads: <https://flow-vid.com/downloads>
- Private vulnerability reports: use the relevant repository's **Security** tab

Open a public repository issue only when it concerns that repository's source, build recipe or
published artifact and contains no private data.

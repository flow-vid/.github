# FlowVid organization files

This is GitHub's special organization `.github` repository. It is intentionally public and is not
an application source repository.

- [`profile/README.md`](profile/README.md) renders on the public
  [`flow-vid`](https://github.com/flow-vid) organization page.
- [`SECURITY.md`](SECURITY.md) provides the default private-reporting guidance for public FlowVid
  repositories that do not define their own policy.
- [`SUPPORT.md`](SUPPORT.md) keeps product support separate from native build-recipe issues.

GitHub documents this repository convention under organization profile and default community health
files.

# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use **Security > Report a vulnerability**
in the affected public repository so maintainers receive the report privately.

Include the affected component and release, reproduction details, expected impact, and any relevant
logs with secrets, tokens, account identifiers, media URLs and personal data removed.

For a security concern in a closed-source FlowVid client or service, use the private contact path at
<https://flow-vid.com/support> and clearly mark the report as a security issue.

## Scope

This organization contains public native media components and build recipes used by FlowVid. Product
support questions, addon troubleshooting and content-source issues are not security reports.
